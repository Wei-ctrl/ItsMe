# It's Me

My personal website — a simple, dependency-free static site (HTML, CSS, JS).

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Publish with GitHub Pages

1. Go to **Settings → Pages** in this repo.
2. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The site will be live at `https://wei-ctrl.github.io/ItsMe/`.
